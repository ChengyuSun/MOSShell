# 第五章 · 桃花源

## 知识锚点

| 锚点 | 解释 |
|------|------|
| 阡陌交通，鸡犬相闻 | 田间小路交叉连通，鸡鸣狗叫彼此能听到。中国文学里对乡村最安静的描述 |
| 其中往来种作 | 人们在田间来来往往——没有神仙、没有法术，就是过日子 |
| 男女衣着，悉如外人 | 他们穿的衣服跟外面一样。如果穿秦朝古装就是时间冻结的仙境——但"悉如外人"，这就是一群普通人 |
| 黄发垂髫，并怡然自乐 | 老人（黄发）和孩子（垂髫）——社会最脆弱的两端——都自得其乐。一个社会的文明程度，看它怎么对待老人和孩子 |
| 见渔人，乃大惊 | 太久没见到外人了。但反应不是警惕——是好奇和热情 |
| 设酒杀鸡作食 | 杀鸡摆酒——对一个陌生人。最高规格的待客 |
| 自云先世避秦时乱 | 祖先为躲避秦朝战乱来此。距今约六百年。六百年与世隔绝 |
| 不知有汉，无论魏晋 | 秦之后是汉（400年）、汉之后是魏、魏之后是晋。外面换了三个朝代——他们全不知道 |
