# 第二章 · 桃花林

## 知识锚点

| 锚点 | 解释 |
|------|------|
| 夹岸数百步 | "夹岸"——两岸夹溪水。画面是纵向的：一条溪、两岸花、从远到近全是粉色 |
| 中无杂树 | 一棵别的树都没有。极致的纯粹。这不是自然生态——第一个暗示这里可能有人 |
| 芳草鲜美 | 不只有头上的桃花，脚下的草也是美的。上下两层，全被美覆盖 |
| 落英缤纷 | "英"是花瓣。"缤纷"——纷乱繁多。四个字里花瓣在动、在飘、在旋转 |
| 渔人甚异之 | "异"——感到奇怪，不是感到美。劳动者的第一反应是"这不对劲"，不是"好漂亮" |
| 欲穷其林 | "穷"是动词——走到尽头。美不足以让他停下，他想知道桃林后面是什么 |
