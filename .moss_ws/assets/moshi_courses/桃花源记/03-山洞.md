# 第三章 · 山洞

## 知识锚点

| 锚点 | 解释 |
|------|------|
| 林尽水源 | 桃林走到头就是溪水源头。山+水，入口坐标被精确定位 |
| 山有小口 | 不是山洞、不是峡谷——"小口"。入口越不起眼，后面的反差越强烈 |
| 仿佛若有光 | 全篇最迷人的五个字。不是"有光"——是"仿佛"、"若有"。暧昧的、不确定的。太亮了反而不敢进 |
| 便舍船 | 渔人把船丢了。船是他唯一的家当、他的生计。第一个不可逆的决定 |
| 初极狭，才通人 | "才"——刚刚够。只能侧身挤进去。空间从无垠桃林骤然收缩到身体极限 |
| 复行数十步 | 在极窄的黑暗中走几十步——每一步都可能是最后一步。他没有回头 |
