# 第六章 · 归来

## 知识锚点

| 锚点 | 解释 |
|------|------|
| 停数日，辞去 | 住了几天才走。但他终究是"外人"——他不属于这里 |
| 不足为外人道也 | 不是"不许说"——是"不值得"。全篇最无奈也最温柔的一句话 |
| 处处志之 | 一出来就到处做记号。越做记号，越证明你已经开始忘了 |
| 寻向所志，遂迷，不复得路 | 沿着记号走——找不到。记号变成了乱画。越想抓住的，越抓不住 |
| 南阳刘子骥 | 真实人物。陶渊明把历史真人插入小说结尾——最后一次让你相信 |
| 未果，寻病终 | "未果"——没去成。"寻病终"——不久病逝。五个字，一条人命 |
| 后遂无问津者 | "问津"——询问渡口。从此再没有人去问路了。全篇结束——没有总结、没有抒情 |

**入场：** Ch05 的 village.png 还在。先清掉，回到粒子主导——灰蓝水流在暗空间漂移。
