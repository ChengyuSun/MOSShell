# 第二章 · 穷其林

> 风格 = 从堆满往回收：桃花林繁华渐退 → 山壁硬切 → 光隙呼吸。全章只聚焦一件事——那束光。
> 台词几乎只念原文。解释只在被打断时展开。

## 知识锚点（仅供被打断时引用，正常表演不讲）

| 锚点 | 一句话 |
|------|--------|
| 渔人甚异之 | 劳动者的直觉——"不对劲"，不是"好美" |
| 欲穷其林 | 美不足以让他停下，好奇心比审美更强 |
| 林尽水源 | 桃林尽头就是溪水源头，入口坐标被精确定位 |
| 山有小口 | 不是山洞、不是峡谷——"小口"。入口越不起眼，反差越强烈 |
| 仿佛若有光 | 全篇最迷人的五个字。不是"有光"——是"仿佛"、"若有"。暧昧的微光最诱人 |

## 本章表演约束

**入场：** 本章是 Ch1 的延续。Ch1 停在 `forest.png` + enchanted + `set_body t="欲穷其林"`。入场**不切布局**（同一 peach_blossom_stage），先做章首设定再续跑。

**转场策略（不用 constrict）：** "林尽水源→便得一山"处用**三箭硬切**——`set_atmosphere enchanted→tense` + `set_background_image forest.png→cave.png` + `audio enchanted.m4a→tense.m4a` 同帧发出。tense 氛围自动激活 `peach-slit` 光隙（呼吸光点），无需额外命令。这是全章唯一的"剪辑点"。

**视觉哲学：** 从密到疏再到聚焦。Ch1 的桃花林峰值（落英缤纷四层堆满）→ Ch2 逐层清退 → 最后只剩暗山壁中央一隙微光。密度曲线 = 从 enchanted 的满，收到 tense 的空，再聚焦到那束光。

**光隙系统：** `peach-slit.tense` = CSS `point-breathe` 3s 呼吸循环 + 三层径向光晕（30px/80px/150px box-shadow）。tense 氛围一开即自动浮现，在屏幕中央偏上位置。

**四层编排（急板核心）：**
- **背景层**：全章仅一次切换——forest.png（桃林，前 2 拍续航）→ cave.png（山壁，硬切后延续到尾）。静图，无背景视频。

- **氛围当剪辑点**：enchanted（续航前 2 拍）→ tense（硬切后激活光隙，延续到结尾）。
