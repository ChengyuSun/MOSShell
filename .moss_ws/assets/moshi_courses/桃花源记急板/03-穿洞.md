# 第三章 · 穿洞

> 便舍船 → 豁然开朗。全篇最高潮——从仅容一人的岩缝压到窒息，然后炸开整个世界。

> 台词几乎只念原文。解释只在被打断时展开。

## 知识锚点（仅供被打断时引用，正常表演不讲）

| 锚点 | 一句话 |
|------|--------|
| 便舍船 | 舍弃来时工具——船是渔人的身份和退路。舍船即无退 |
| 从口入 | "口"字精妙：不是门、不是洞，是山体张开的一张嘴 |
| 初极狭，才通人 | 极狭→极广的蓄力。入口越小、反差越烈。陶渊明的空间魔法 |
| 复行数十步 | 黑暗中的坚持。几十步在窄缝里是一段漫长的心理距离 |
| 豁然开朗 | 全文最暴力的四个字。不是"渐渐开阔"——是"豁然"。瞬间炸开 |
| 土地平旷，屋舍俨然 | 炸开后的第一个画面。平旷=安全感，俨然=有人精心维护 |
